# Workbox -- Google's Service Worker Library

Workbox is a set of production-ready service worker libraries and tooling from the Chrome team. It simplifies common service worker routing and caching patterns, handling the complexity of precaching, runtime caching, and offline support.

---

## Installation

### Via Build Tools (Recommended)

```bash
# npm
npm install workbox-webpack-plugin --save-dev

# yarn
yarn add workbox-webpack-plugin --save-dev

# pnpm
pnpm add workbox-webpack-plugin -D
```

### Via CDN (No Build Step)

```javascript
import { precacheAndRoute } from 'https://storage.googleapis.com/workbox-cdn/releases/7.0.0/workbox-window.prod.mjs';
```

## Core Modules

| Module | Purpose |
|---|---|
| `workbox-routing` | Intercept requests and route them to strategies |
| `workbox-strategies` | Caching strategy implementations |
| `workbox-precaching` | Precache assets during SW install |
| `workbox-cacheable-response` | Filter by response status/headers |
| `workbox-expiration` | LRU eviction and TTL management |
| `workbox-background-sync` | Queue failed requests for replay |
| `workbox-navigation-preload` | Speed up network-first navigations |
| `workbox-broadcast-update` | Notify pages when cache updates |
| `workbox-window` | Register SW from page context |

## Precaching

Precache assets at service worker installation time. Workbox injects a manifest of URLs from your build.

```javascript
import { precacheAndRoute } from 'workbox-precaching';

// self.__WB_MANIFEST is replaced at build time
precacheAndRoute(self.__WB_MANIFEST);

// Manual precaching
import { precacheAndRoute } from 'workbox-precaching';

precacheAndRoute([
  { url: '/index.html', revision: '1' },
  { url: '/styles/main.css', revision: '1' },
  { url: '/scripts/app.js', revision: '1' },
]);
```

## Runtime Caching Strategies

### Cache First

```javascript
import { registerRoute } from 'workbox-routing';
import { CacheFirst } from 'workbox-strategies';
import { ExpirationPlugin } from 'workbox-expiration';

registerRoute(
  ({ request }) => request.destination === 'image',
  new CacheFirst({
    cacheName: 'images',
    plugins: [
      new ExpirationPlugin({
        maxEntries: 60,
        maxAgeSeconds: 30 * 24 * 60 * 60, // 30 days
      }),
    ],
  })
);
```

### Network First

```javascript
import { registerRoute } from 'workbox-routing';
import { NetworkFirst } from 'workbox-strategies';

registerRoute(
  ({ request }) => request.mode === 'navigate',
  new NetworkFirst({
    cacheName: 'pages',
    networkTimeoutSeconds: 3, // Fall back to cache after 3s
  })
);
```

### Stale While Revalidate

```javascript
import { registerRoute } from 'workbox-routing';
import { StaleWhileRevalidate } from 'workbox-strategies';

registerRoute(
  ({ request }) => request.destination === 'style' || request.destination === 'script',
  new StaleWhileRevalidate({
    cacheName: 'static-resources',
  })
);
```

### Network Only (No Caching)

```javascript
import { registerRoute } from 'workbox-routing';
import { NetworkOnly } from 'workbox-strategies';

registerRoute(
  ({ url }) => url.pathname.startsWith('/api/write'),
  new NetworkOnly(),
  'POST'
);
```

## Routing Patterns

### Match by Request Destination

```javascript
registerRoute(
  ({ request }) => request.destination === 'image',
  new CacheFirst({ cacheName: 'images' })
);
```

### Match by URL Pattern (Regex)

```javascript
registerRoute(
  ({ url }) => url.pathname.match(/\/api\/v1\/(.*)/),
  new NetworkFirst({ cacheName: 'api-v1' })
);
```

### Match by HTTP Method

```javascript
registerRoute(
  ({ url, request }) => request.method === 'POST' && url.pathname.startsWith('/api/'),
  new NetworkOnly(),
  'POST'
);
```

### Match by Origin

```javascript
import { SameOriginPlugin } from 'workbox-routing';

registerRoute(
  ({ url }) => url.origin === self.location.origin,
  new StaleWhileRevalidate()
);
```

### Catch-All Fallback

```javascript
import { CatchHandler } from 'workbox-strategies';

// Register a catch-all at the end
registerRoute(
  ({ request }) => request.destination === 'document',
  new NetworkFirst({
    cacheName: 'pages',
    plugins: [
      {
        handlerDidError: async ({ request }) => {
          return caches.match('/offline.html');
        },
      },
    ],
  })
);
```

## Cacheable Response Plugin

Only cache responses with specific status codes:

```javascript
import { CacheableResponsePlugin } from 'workbox-cacheable-response';

new CacheFirst({
  cacheName: 'images',
  plugins: [
    new CacheableResponsePlugin({
      statuses: [0, 200], // Cache opaque responses and OK
    }),
  ],
});
```

## Expiration Plugin

Manage cache size and age:

```javascript
import { ExpirationPlugin } from 'workbox-expiration';

new CacheFirst({
  cacheName: 'fonts',
  plugins: [
    new ExpirationPlugin({
      maxEntries: 30,       // Max items in cache
      maxAgeSeconds: 365 * 24 * 60 * 60, // 1 year
      purgeOnQuotaError: true, // Auto-purge when storage is full
    }),
  ],
});
```

## Background Sync

Replay failed requests when connectivity returns:

```javascript
import { BackgroundSyncPlugin } from 'workbox-background-sync';
import { NetworkOnly } from 'workbox-strategies';
import { registerRoute } from 'workbox-routing';

const bgSyncPlugin = new BackgroundSyncPlugin('apiQueue', {
  maxRetentionTime: 60 * 24, // Retry for up to 24 hours
});

registerRoute(
  /\/api\/.*\/submit/,
  new NetworkOnly({ plugins: [bgSyncPlugin] }),
  'POST'
);
```

## Navigation Preload

Speed up network-first navigation requests:

```javascript
import { NavigationRoute } from 'workbox-routing';
import { NetworkFirst } from 'workbox-strategies';
import { enable as enableNavigationPreload } from 'workbox-navigation-preload';

// Enable navigation preload
self.addEventListener('activate', (event) => {
  event.waitUntil(enableNavigationPreload());
});

// Use navigation preload with NetworkFirst
const navigationRoute = new NavigationRoute(
  new NetworkFirst({
    cacheName: 'navigation',
    plugins: [
      new CacheableResponsePlugin({ statuses: [0, 200] }),
    ],
  })
);

registerRoute(navigationRoute);
```

## Broadcast Update

Notify pages when cached content updates:

```javascript
import { BroadcastCacheUpdate } from 'workbox-broadcast-update';

new CacheFirst({
  cacheName: 'static',
  plugins: [
    new BroadcastCacheUpdate({
      channelName: 'cache-updates',
    }),
  ],
});
```

Listen in your page:

```javascript
// In your page JS
const channel = new BroadcastChannel('cache-updates');
channel.onmessage = (event) => {
  if (event.data.type === 'CACHE_UPDATED') {
    console.log('New content available -- refresh to update');
  }
};
```

## Fallback Responses

Provide offline fallback pages:

```javascript
import { WarmCacheStrategy } from 'workbox-strategies';

// Serve a fallback page for failed navigations
registerRoute(
  ({ request }) => request.mode === 'navigate',
  async ({ request }) => {
    const cachedPage = await caches.match('/offline.html');
    return cachedPage || Response.error();
  }
);
```

## Workbox Recipes (Pre-configured Patterns)

```javascript
import {
  pageCache,
  imageCache,
  staticResourceCache,
  warmStrategyCache,
} from 'workbox-recipes';
import { StaleWhileRevalidate, CacheFirst } from 'workbox-strategies';
import { ExpirationPlugin } from 'workbox-expiration';

// Page cache (NetworkFirst with offline fallback)
pageCache();

// Image cache (CacheFirst with expiration)
imageCache();

// Static resources (StaleWhileRevalidate)
staticResourceCache();

// Warm cache on install
warmStrategyCache({
  urls: ['/index.html', '/offline.html'],
  strategy: new StaleWhileRevalidate(),
});
```

## Registering from the Page (workbox-window)

```javascript
import { Workbox } from 'workbox-window';

if ('serviceWorker' in navigator) {
  const wb = new Workbox('/sw.js');

  // Listen for SW updates
  wb.addEventListener('controlling', () => {
    window.location.reload();
  });

  // Register
  wb.register();
}
```

## Complete Service Worker Example

```javascript
import { precacheAndRoute } from 'workbox-precaching';
import { registerRoute } from 'workbox-routing';
import { CacheFirst, NetworkFirst, StaleWhileRevalidate, NetworkOnly } from 'workbox-strategies';
import { ExpirationPlugin } from 'workbox-expiration';
import { CacheableResponsePlugin } from 'workbox-cacheable-response';
import { BackgroundSyncPlugin } from 'workbox-background-sync';
import { NavigationRoute } from 'workbox-routing';
import { enable as enableNavigationPreload } from 'workbox-navigation-preload';

// Precache
precacheAndRoute(self.__WB_MANIFEST);

// Enable navigation preload
self.addEventListener('activate', (event) => {
  event.waitUntil(enableNavigationPreload());
});

// HTML: Network first with offline fallback
registerRoute(
  new NavigationRoute(
    new NetworkFirst({
      cacheName: 'pages',
      plugins: [
        new CacheableResponsePlugin({ statuses: [0, 200] }),
      ],
    })
  )
);

// Images: Cache first with expiration
registerRoute(
  ({ request }) => request.destination === 'image',
  new CacheFirst({
    cacheName: 'images',
    plugins: [
      new CacheableResponsePlugin({ statuses: [0, 200] }),
      new ExpirationPlugin({ maxEntries: 60, maxAgeSeconds: 30 * 24 * 3600 }),
    ],
  })
);

// Static assets: Stale while revalidate
registerRoute(
  ({ request }) => ['style', 'script', 'worker'].includes(request.destination),
  new StaleWhileRevalidate({ cacheName: 'static' })
);

// API writes: Network only with background sync
const bgSync = new BackgroundSyncPlugin('apiQueue', {
  maxRetentionTime: 60 * 24,
});

registerRoute(
  ({ request }) => request.method === 'POST',
  new NetworkOnly({ plugins: [bgSync] })
);

// API reads: Network first
registerRoute(
  ({ url }) => url.pathname.startsWith('/api/'),
  new NetworkFirst({
    cacheName: 'api',
    networkTimeoutSeconds: 5,
  })
);
```
