# TanStack Router v1 - Documentation

**Package:** `@tanstack/react-router` v1.170.32
**Docs:** https://tanstack.com/router/latest/docs/framework/react

## Overview

TanStack Router is a type-safe router for React with file-based routing, nested routes, search param validation, data loaders, and end-to-end TypeScript inference.

### Key Features
- 100% inferred TypeScript support
- Type-safe navigation
- Nested routing and layout routes (pathless)
- Built-in search params validation
- Data loaders with caching and revalidation
- Automatic code splitting
- Parallel route loading

## File-Based Routing

Routes live in `src/routes/` directory:

```
src/routes/
  __root.tsx          # Root layout
  index.tsx           # / route
  about.tsx           # /about route
  contacts._layout.tsx  # Layout for contacts
  contacts.tsx        # /contacts route
  contacts.$id.tsx    # /contacts/:id route
  contacts.$id.edit.tsx # /contacts/:id/edit route
```

### Route Configuration

```typescript
// src/routes/__root.tsx
import { createRootRoute, Outlet } from '@tanstack/react-router'

export const Route = createRootRoute({
  component: () => (
    <div>
      <Outlet />
    </div>
  ),
})
```

### Page Routes

```typescript
// src/routes/index.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: HomePage,
})

function HomePage() {
  return <div>Welcome!</div>
}
```

### Parameterized Routes

```typescript
// src/routes/contacts.$id.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/contacts/$id')({
  component: ContactDetail,
})

function ContactDetail() {
  const { id } = Route.useParams()
  return <div>Contact {id}</div>
}
```

### Layout Routes (Pathless)

```typescript
// src/routes/contacts._layout.tsx
import { createFileRoute, Outlet } from '@tanstack/react-router'

export const Route = createFileRoute('/contacts/_layout')({
  component: ContactLayout,
})

function ContactLayout() {
  return (
    <div>
      <nav>Contacts navigation</nav>
      <Outlet />
    </div>
  )
}
```

## Navigation

### Programmatic Navigation

```typescript
import { useNavigate, useRouter } from '@tanstack/react-router'

function MyComponent() {
  const navigate = useNavigate()

  const handleClick = () => {
    navigate({ to: '/contacts/$id', params: { id: '123' } })
  }

  // With search params
  navigate({
    to: '/search',
    search: { query: 'hello', page: 1 },
  })

  // With replace (no history entry)
  navigate({
    to: '/dashboard',
    replace: true,
  })
}
```

### Link Component

```typescript
import { Link } from '@tanstack/react-router'

// Basic link
<Link to="/about">About</Link>

// With params
<Link to="/contacts/$id" params={{ id: '123' }}>Contact</Link>

// With search params
<Link to="/search" search={{ query: 'hello', page: 1 }}>Search</Link>

// Active link styling
<Link
  to="/about"
  activeProps={{ className: 'font-bold text-blue-600' }}
  inactiveProps={{ className: 'text-gray-600' }}
>
  About
</Link>
```

## Route Context and Data Loading

### Loader

```typescript
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/contacts/$id')({
  loader: async ({ params }) => {
    const contact = await fetchContact(params.id)
    return { contact }
  },
  component: ContactDetail,
})

function ContactDetail() {
  const { contact } = Route.useLoaderData()
  return <div>{contact.name}</div>
}
```

### Route Context

```typescript
import { createFileRoute, redirect } from '@tanstack/react-router'

export const Route = createFileRoute('/dashboard')({
  beforeLoad: async ({ context }) => {
    if (!context.auth?.user) {
      throw redirect({ to: '/login' })
    }
  },
  loader: async ({ context }) => {
    const data = await fetchDashboardData(context.auth.user.id)
    return { data }
  },
})

// Pass context from root
export const RootRoute = createRootRoute({
  context: async () => ({
    auth: await getAuth(),
  }),
})
```

## Search Params Validation

```typescript
import { createFileRoute } from '@tanstack/react-router'
import { z } from 'zod'

const searchSchema = z.object({
  page: z.number().default(1),
  query: z.string().default(''),
  sort: z.enum(['asc', 'desc']).default('asc'),
})

export const Route = createFileRoute('/search')({
  validateSearch: (search) => searchSchema.parse(search),
  component: SearchPage,
})

function SearchPage() {
  const { page, query, sort } = Route.useSearch()
  // page, query, sort are all properly typed!
}
```

## Router Configuration

```typescript
// src/routeTree.gen.ts (auto-generated by file-based routing)
// src/router.tsx
import { createRouter, createFileRoute } from '@tanstack/react-router'
import { routeTree } from './routeTree.gen'

export const router = createRouter({
  routeTree,
  defaultPreload: 'intent', // Preload on hover/focus
  defaultStaleTime: 5000,
})

// Declare module for type safety
declare module '@tanstack/react-router' {
  interface Register {
    router: typeof router
  }
}
```

## Code Splitting

Each route file is automatically code-split. For manual splits:

```typescript
import { lazy, Suspense } from 'react'
import { createFileRoute } from '@tanstack/react-router'

const HeavyComponent = lazy(() => import('./HeavyComponent'))

export const Route = createFileRoute('/heavy')({
  component: () => (
    <Suspense fallback={<div>Loading...</div>}>
      <HeavyComponent />
    </Suspense>
  ),
})
```

## Error Handling

```typescript
export const Route = createFileRoute('/contacts/$id')({
  errorComponent: ({ error }) => {
    return <div>Error loading contact: {error.message}</div>
  },
  notFoundComponent: () => {
    return <div>Contact not found</div>
  },
  component: ContactDetail,
})
```

## Key Patterns

1. Use file-based routing for automatic code splitting
2. Validate search params with Zod schemas
3. Use `beforeLoad` for auth guards and redirects
4. Use `loader` for data fetching with automatic caching
5. Use `Link` component for navigation (supports preloading)
6. Use `Route.useParams()`, `Route.useSearch()`, `Route.useLoaderData()` for type-safe data access
7. Use `throw redirect()` in `beforeLoad` for auth redirects
